本地大模型部署自查包

跑大模型之前，先花两分钟把机器的底摸清楚 —— 少走弯路，也不会买错模型。

开源模型对不上你的机器，八成不是模型的问题，是显存、驱动、编译架构这三样里有一个不对。 这个包帮你先把这三样查清楚，再算出一组能跑起来的参数。

下载 LLM-Setup-Check-v1.0.zip
4.7 KB · 解压即用 · 只依赖系统自带的 PowerShell / bash / python3，不需要 pip install 任何包

里面有什么

文件干什么
`检查.ps1`Windows：一键查显卡、驱动、内存、磁盘，并给出“你这张卡适合跑多大模型”的建议
`检查.sh`Linux / WSL：同上，另外列出已装的推理工具
`生成启动参数.py`按你的显存和模型大小，算一组能跑起来的 llama.cpp 参数
`使用说明.md`用法 + 常见报错速查（PTX 不兼容 / OOM / KV 量化 / 跑得慢）

怎么用

# Windows（右键 PowerShell 运行，或）
powershell -ExecutionPolicy Bypass -File .\检查.ps1

# Linux / WSL
bash 检查.sh

# 算参数：11 GB 显存跑 5.7 GB 的 Q4 模型，上下文 32K
python3 生成启动参数.py --vram 11 --model-gb 5.7 --ctx 32768
